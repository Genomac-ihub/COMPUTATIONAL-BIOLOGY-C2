 This week focuses on the essential data manipulation and wrangling skills every computational biologist should have — using the powerful Python library: **Pandas**.

- The importance of structured and clean data in computational biology  
- Practical tools for wrangling, cleaning, and merging real-world biological datasets  
- Pandas workflows for transforming raw tables into analysis-ready formats

**🎯 Learning Objectives**  
By the end of this week, you should be able to:  
- ✅ Load, inspect, and explore biological datasets using Pandas  
- ✅ Clean messy data: handle missing values, rename columns, reformat structures  
- ✅ Merge multiple datasets based on shared biological identifiers (e.g., patient ID, gene name)  
- ✅ Apply filtering, grouping, and transformation operations for feature engineering
