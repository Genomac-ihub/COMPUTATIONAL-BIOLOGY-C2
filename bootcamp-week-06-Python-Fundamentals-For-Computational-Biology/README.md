# 🐍 Week 6: Python Fundamentals for Bioinformatics

Welcome to **Week 6** of the Computational Biology Bootcamp!  
This week we introduce you to one of the most powerful and widely used languages in bioinformatics — **Python**.

You'll learn the building blocks of Python and how they apply to solving real-world biological data problems.

---

## 📚 Overview

This week's module covers:

### 🧠 Python Programming Essentials
- **Variables and data types**
- **Data structures**: lists, dictionaries, tuples
- **Control flow**: if-else statements, loops
- **Functions**: writing and using reusable code blocks

### 🔄 Python in Bioinformatics
- Compared to R, Bash, or Perl, Python is:
  - More readable and beginner-friendly
  - Highly versatile for **data wrangling**, **text parsing**, and **pipeline automation**
  - Backed by a strong ecosystem of bioinformatics libraries

---

## 💡 Learning Objectives

By the end of this week, you will be able to:

- Write basic Python scripts for handling genomic or biological data  
- Use **loops** and **functions** to automate repetitive tasks  
- Understand the advantages of using Python in bioinformatics workflows

---

## 🧪 Example Topics

- Read a FASTA file and count the number of sequences  
- Parse tabular data to extract gene or mutation information  
- Write a function to search for specific DNA patterns  

> These examples will help you connect programming logic with real-world bioinformatics tasks.
