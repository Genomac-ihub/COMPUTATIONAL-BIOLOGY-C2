# 🐧 Week 5: Linux for Bioinformatics

Welcome to **Week 5** of the Computational Biology Bootcamp!  
This week introduces you to **Linux-based environments** and their crucial role in modern bioinformatics workflows — especially when working with command-line tools and high-throughput sequencing data.

---

## 📚 Overview

In this module, you will:

### 💻 Learn Linux Essentials
- How to set up and navigate a Linux environment
- Key Bash commands for file and data management
- Organizing bioinformatics files and directories

### 🧪 Perform Quality Control Using FastQC
- Install and run **FastQC** on **CNV** (Copy Number Variation) datasets
- Interpret basic output and quality control metrics

### 📁 Work With Key Genomic Data
- Introduction to **GDC Manifest Files**
- Basics of working with **CNV data**
- A brief look into **RNA-Seq analysis** workflows

---

## 💬 Why Linux?

Linux is the backbone of bioinformatics:

- 🔁 Enables **reproducible, scriptable workflows**
- ⚙️ Supports most bioinformatics tools and packages
- 🧵 Handles large-scale data efficiently
- 🧠 Encourages understanding of the systems behind the tools

---

## 💡 Learning Objectives

By the end of this week, you should be able to:

- Use essential Linux and Bash commands to navigate, create, and manage files
- Run bioinformatics software like **FastQC** from the command line
- Perform preliminary quality control on genomic data
- Understand the importance of command-line workflows in reproducible research
