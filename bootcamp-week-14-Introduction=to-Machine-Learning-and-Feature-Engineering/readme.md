**📚 Overview**  
Machine learning enables powerful discoveries in genomics, from predicting **disease risk** to uncovering  **mutation signatures** and  **drug responses**.  
   
 However, ML is only as good as the **features** it learns from. In this module, we focus on:  
- **Supervised learning basics**: training ML models on labeled biological datasets  
- **Feature engineering**: turning genomic data (mutations, expression, copy number, etc.) into usable input vectors  
- **Best practices in feature selection**: ensuring reproducibility and biological relevance
