# 🧬 Week 9: APIs, Data Merging, and Transformation

Welcome to **Week 9** of the Computational Biology Bootcamp!  
This module focuses on practical techniques for **retrieving**, **merging**, and **transforming** data — key steps in preparing clinical and omics datasets for meaningful analysis.

---

## 📚 Overview

In this module, we explore:

### 🌐 Using APIs for Data Retrieval

- How to access biological and clinical datasets using APIs
- Examples of common bioinformatics APIs (e.g., cBioPortal, Ensembl REST API, NCBI E-utilities)

### 🔗 Data Integration & Merging

- Merging clinical and omics data
- Handling missing values, aligning identifiers, and resolving data format differences

### 🧪 Normalization Techniques

- Why normalization is essential for downstream analysis
- Common normalization strategies in omics and clinical datasets

---

## 💬 Key Discussion Topics

- Challenges in integrating **heterogeneous data sources**
- Importance of **data consistency** and **standardization**
- Role of **normalization** in removing technical bias

---

## 💡 Learning Objectives

By the end of this week, you should be able to:

- ✅ Retrieve data from APIs for biological research
- ✅ Merge clinical and omics data into structured datasets
- ✅ Apply normalization techniques to prepare data for analysis
- ✅ Understand the implications of data quality and harmonization for machine learning and statistical models

---

## 🧪 Practical Task

This week includes a hands-on data analysis task involving real-world clinical data.  
You’ll practice:

- Retrieving and loading datasets via an API
- Merging two or more datasets into a unified structure
- Normalizing the data for downstream applications (e.g., feature extraction, machine learning)

📂 Detailed instructions and datasets will be provided in the `notebooks/` or `materials/` folder.
